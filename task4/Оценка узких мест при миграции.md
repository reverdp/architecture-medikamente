## Оценка узких мест при миграции

### 1. Ключевые процессы и компоненты, затрагиваемые миграцией

| Процесс / компонент      | Что меняется                                                 |
|--------------------------|--------------------------------------------------------------|
| Регистрация пациента     | Excel и файлы заменяются CRM                                 |
| Запись к врачу           | журналы Excel заменяются Appointment Service                 |
| Медицинская карта        | файлы и сканы заменяются Medical Records Service             |
| Лабораторные анализы     | ручной обмен через файлы заменяется API-интеграцией          |
| Оплата                   | Excel/1С/ККМ интегрируются через платёжный шлюз              |
| Документы                | общий диск заменяется защищённым хранилищем                  |
| Аналитика                | Excel-отчёты заменяются Data Lake/BI/ML                      |
| Инфраструктура           | один локальный сервер заменяется отказоустойчивой платформой |
| Безопасность             | добавляются IAM, DLP, Audit                                  |
