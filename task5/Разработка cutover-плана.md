## Разработка cutover-плана

### 1. Выбор стратегии миграции

Для компании Медикаменте наиболее подходящая стратегия - Parallel run

#### Почему выбран Parallel run

Текущая система содержит критичные данные и процессы:
* запись пациентов к специалистам
* медицинские карты
* результаты анализов
* платежи
* интеграции с 1С и ККМ
* документы и сканы пациентов
* будущие порталы пациента и сотрудников

Полная одномоментная миграция слишком рискованна: данные сейчас разрознены в Excel, PDF/JPG, 1С и файловом хранилище. \
Если выполнить резкое переключение, есть риск потерять данные, нарушить запись пациентов, некорректно перенести медицинские карты или остановить кассовые операции

Parallel run позволяет сначала запустить новую систему рядом со старой, сверять результаты, постепенно переводить пользователей и снижать риск простоя

Преимущества:
* Минимизация риска остановки бизнеса
* Возможность сверки данных
* Постепенное обучение сотрудников
* Контролируемый запуск новых сервисов
* Возможность быстрого отката

Ограничения:
* Нужно поддерживать две системы одновременно
* Возможна рассинхронизация данных
* Увеличивается нагрузка на сотрудников
* Сложнее поддерживать отчётность
