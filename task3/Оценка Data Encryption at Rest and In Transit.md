## Оценка Data Encryption at Rest and In Transit

| Данные                                      | В чём необходимость защиты                                           | Инструменты защиты                                                                             |
| ------------------------------------------- | -------------------------------------------------------------------- |------------------------------------------------------------------------------------------------|
| ФИО, телефон, email, дата рождения пациента | Это персональные данные. Утечка позволяет идентифицировать пациента  | Шифрование БД at-rest, TLS, маскирование в UI/логах, RBAC, DLP                                 |
| Адрес, паспортные данные, анкеты            | Высокочувствительные идентификационные данные                        | Field-level encryption, Secure Document Storage, DLP, запрет экспорта, аудит доступа           |
| Медицинская карта                           | Содержит медицинскую тайну: жалобы, диагнозы, назначения, заключения | Шифрование at-rest, RBAC, аудит каждого просмотра, запрет email-отправки                       |
| Диагнозы и заключения                       | Критически чувствительная медицинская информация                     | Column-level encryption, masking в логах                                                       |
| Результаты лабораторных анализов            | Раскрывают состояние здоровья пациента                               | mTLS с лабораторией, OAuth2, шифрование БД, API Gateway, audit log                             |
| Записи к врачу                              | Даже факт записи к специалисту может раскрывать медицинский контекст | TLS, RBAC, запрет экспорта                                                                     |
| Платежи и чеки                              | Платёж может быть связан с медицинской услугой и пациентом           | TLS, шифрование БД/1С, минимизация медицинских деталей, аудит, доступ только кассе/бухгалтерии |
| Документы PDF/JPG                           | Содержат договоры, согласия, анкеты и сканы                          | Шифрование файлового хранилища, DLP, Microsoft Purview labels, аудит скачивания                |
| Email и вложения                            | Возможный канал утечки PII/MEDICAL                                   | Microsoft Purview DLP, sensitivity labels, шифрование почты, запрет вложений с MEDICAL         |
| Бэкапы                                      | Содержат полный объём продуктивных данных                            | Шифрование бэкапов, отдельный доступ, аудит восстановления                                     |
| Логи                                        | Могут случайно содержать PII, токены, диагнозы                       | Маскирование, запрет логирования чувствительных полей                                          |
| BI/ML-датасеты                              | Могут позволить восстановить личность пациента                       | Обезличивание, псевдонимизация, Secure Data Lake, контроль lineage                             |
